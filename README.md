# 🧠 C-MNIST Neural Network

A lightweight, high-performance Multi-Layer Perceptron (MLP) written in pure **C99** from scratch. Designed for handwritten digit recognition using the classic MNIST dataset. 

Zero external ML frameworks, zero magic — just pure mathematics, standard C libraries, and manual memory management.

---

## ✨ Features

* **Zero Heavy Dependencies:** Built using only C standard headers (`stdio.h`, `stdlib.h`, `math.h`, etc.).
* **Custom Binary Parser:** Built-in loader for MNIST high-endian idx binary format files.
* **Manual Backpropagation:** Full implementation of forward pass, loss calculation, and stochastic gradient descent (SGD).
* **Model Persistence:** Custom serialization system to save and load network weights (`weights.bin`) for incremental/online training.
* **Double Free Guard & Memory Management:** Built-in structural safety flags and clean heap cleanup.

---

## 📊 Architecture & Performance

| Parameter | Value |
| :--- | :--- |

## 🚀 Quick Start

### 1. Requirements & Setup
Make sure you have `gcc` and `make` installed. Download the MNIST dataset and place the uncompressed binary files inside the `train/` directory:
* `train/train-images-idx3-ubyte`
* `train/train-labels-idx1-ubyte`

### 2. Building and Running

* **Build the project:**
  ```bash
  make
  ```
* **Build and run:**
  ```bash
  make run
  ```
* **Clean:**
  ```bash
  make clean
  ```
